# Hook Engineering — Ogilvy + Hormozi Doctrine

## Purpose
Generate high-retention hooks for short-form and long-form video content. Every video lives or dies in the first 3 seconds.

---

## OGILVY PRINCIPLES FOR HOOKS

1. **The headline is 80% of the work.** Five times as many people read the headline as read the body. Your hook IS the video.
2. **Specific promise > vague promise.** "How to get 10K views in 7 days" beats "How to grow on YouTube."
3. **Concrete data > general claims.** "94% of creators" beats "most creators." Numbers stop the scroll.
4. **"Who else wants X" > "Learn X."** Imply community and shared desire, not a lecture.
5. **News format works.** "New: Claude Code can now..." triggers curiosity like a newspaper headline.
6. **Benefit in the headline.** Don't be clever—be clear. What does the viewer GET?

## HORMOZI PRINCIPLES FOR HOOKS

1. **Curiosity gap:** Reveal the RESULT, hide the METHOD. Show the output, make them stay for the how.
2. **Specificity:** Never "a lot" or "many." Always "23 videos," "3 hours," "$5,000."
3. **Proof upfront:** Show the finished product, the result, the dashboard—BEFORE explaining.
4. **Contrarian:** Contradict what everyone believes. "CapCut is dead" gets more clicks than "Try this editor."
5. **Stack value:** List everything they'll get. Make the perceived value so high they can't scroll past.
6. **Urgency without manipulation:** "This works right now in 2026" not "limited time."

## THE 6 HOOK TYPES

### 1. STAT HOOK
Pattern: "[Surprising number] + [unexpected claim]"
Examples:
- "El 94% de creadores no sabe que Claude Code puede hacer esto"
- "Solo 3% de videos llegan a 10K views. Aqui esta por que."
- "In 47 minutes I built what an agency charges $5K for"

### 2. STORY HOOK
Pattern: "[Timeframe] + [impressive result] + [relatable method]"
Examples:
- "En 3 horas construi lo que una agencia cobra $5,000"
- "I quit my editing software and built my own in a weekend"
- "Last week I had 0 subscribers. This is what changed."

### 3. CONTRARIAN HOOK
Pattern: "Stop/Don't + [common belief everyone holds]"
Examples:
- "Dejen de usar CapCut para esto—hay algo mejor"
- "Editing your own videos is a waste of time. Here's why."
- "You don't need a $2K camera. Your Samsung is enough."

### 4. LIST HOOK
Pattern: "[Number] + [skills/things/tools] + [context]"
Examples:
- "7 cosas que Claude Code hace que nadie te dice"
- "5 AI tools replacing entire content teams in 2026"
- "Las 3 composiciones de Remotion que todo creador necesita"

### 5. QUESTION HOOK
Pattern: "Why/How + [pain point the audience recognizes]?"
Examples:
- "Por que tu video no llega a 10K views?"
- "Why do iPhone videos always look better than Samsung?"
- "How are solo creators outproducing 10-person teams?"

### 6. TRANSFORMATION HOOK
Pattern: "[Before state] → [After state] + [simple method]"
Examples:
- "Samsung quality → iPhone quality con 1 linea de CSS"
- "Boring talking head → Professional video con Remotion"
- "0 to 10K views: my exact content system"

---

## HOOK GENERATION PROCESS

For every video, generate 5 hooks using different types, then rank them:

1. Write one hook per type (pick the 5 most relevant types)
2. Score each 1-10 on:
   - **Curiosity (1-10):** Does it create an open loop?
   - **Specificity (1-10):** Are there concrete numbers/details?
   - **Relevance (1-10):** Does the ICP (Latin American creators using AI) care?
3. Pick the top 2, A/B test as thumbnail + first 3 seconds
4. The winner becomes the canonical hook, losers become potential Shorts hooks

## HOOK FORMATTING RULES

- Maximum 12 words for video hooks
- Maximum 8 words for thumbnail text
- Always include a number if possible
- Use power words: "exacto," "secreto," "gratis," "nuevo," "ahora"
- Spanish hooks: direct, no formal "usted"—use "tu" register
- English hooks: casual, confident, no hedging ("maybe," "might," "I think")
